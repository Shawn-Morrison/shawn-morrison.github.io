# Trying New Restaurants  

---

## Project Overview

This repository contains a fully planned and documented two-page static website titled **"Trying New Restaurants."**

The project highlights a personal hobby—discovering local restaurants while traveling—and demonstrates the ability to manage a digital project from concept to completion using structured project management principles from *The Unofficial Project Manager (PMUPM)*.

This repository serves as a professional portfolio artifact showcasing:

- Project planning and documentation
- Risk analysis using the TAME framework
- Work Breakdown Structure (WBS)
- HTML and CSS implementation
- Organized GitHub repository structure

## Repository Structure

This project is organized into two primary areas:

### Root Directory (Website Files)

- `index.html` – Homepage featuring restaurant travel photo gallery  
- `about.html` – Explanation of the purpose and process behind trying new restaurants  
- `style.css` – External stylesheet applied consistently across both pages  
- `README.md` – Project overview and navigation guide

## Project Purpose

The purpose of this project was to:

- Apply foundational HTML and CSS skills  
- Demonstrate structured project planning  
- Manage scope and risk intentionally  
- Deliver a complete and professional GitHub repository  
- Synthesize course concepts into a cohesive final product  

Rather than simply building a webpage, this project was approached as a managed initiative with defined scope, risks, constraints, deliverables, and review cycles.

## Technical Overview

- Built using basic HTML and CSS  
- Two-page static structure  
- External stylesheet for consistency  
- Public GitHub repository  
- Organized documentation using Markdown  

No JavaScript or external frameworks were used, in alignment with the defined project scope.
